# SAP Almacén de Obras (WMS)
Sistema de gestión de almacén, herramientas serializadas y consumibles para obras de construcción.

## Estructura del Proyecto
- `backend/`: API REST en Node.js + TypeScript
- `frontend/`: App PWA Fiori Mobile en React
- `database/`: Scripts SQL para PostgreSQL
- `render.yaml`: Configuración de despliegue en Render
